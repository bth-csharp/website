I objektorienterad programmering (OOP) så har vi klasser och objekt. 

En **klass** är en mall (ritning) för hur objekt ska se ut. Den beskriver vilken data och vilka funktioner objekten ska ha.

Ett **objekt** är en instans av en klass, alltså något som skapas från mallen.

**Attribut** är variabler i en klass som beskriver objektets egenskaper.

**Metoder** är funktioner som finns i en klass. De beskriver vad ett objekt kan göra.

Ett **statiskt attribut** tillhör klassen själv, inte varje objekt. Alla objekt delar samma värde.

En **statisk metod** tillhör också klassen istället för objekten. Den anropas via klassnamnet.

Vi tränar på dessa begrepp och liknande begrepp inom OOP genom dessa övningsuppgifter.

Skapa ett console-projekt och testa koden eller kör i en onlinekompilator.

## Övning 1 - Skapa en klass Book

Skapa en klass som heter **Book**. Klassen ska ha tre privata attribut:

Titel (string)
Författare (string)
AntalSidor (int)

Skapa sedan en konstruktor som tar alla tre värdena som parametrar.
Gör följande i "Program.cs":

1. Skapa ett objekt av klassen Book.
1. Skriv ut informationen om boken i terminalen.
1. Byt författare och skriv ut författarens namn.


<details>
<summary>Lösningsförslag Övning 1</summary>

```csharp title="Klassen Book"
class Book
{
    private string _title;
    private string _author;
    private int _numberOfPages;

    public Book(string title, string author, int pages)
    {
        this._title = title;
        this._author = author;
        this._numberOfPages = pages;
    }

    public string GetTitle()
    {
        return this._title;
    }

    public string GetAuthor()
    {
        return this._author;
    }

    public void SetAuthor(string author)
    {
        this._author = author;
    }

    public int GetNumberOfPages()
    {
        return this._numberOfPages;
    }
}
```

Vi har följande kod i huvudprogrammet.

```csharp title="Huvudprogrammet, kod i Program.cs"
// Skapa ett objekt av klassen Book.
Book book = new Book("Dune", "Frank Herbert", 412);

// Skriv ut informationen om boken i terminalen.
Console.WriteLine($"Title: {book.GetTitle()}");
Console.WriteLine($"Author: {book.GetAuthor()}");
Console.WriteLine($"Pages: {book.GetNumberOfPages()}");

// Byt författare och skriv ut författarens namn.
book.SetAuthor("Frank Herbert");
Console.WriteLine($"Author: {book.GetAuthor()}");
```

</details>

## Övning 3 - En liten minisimulator, Husdjur

Skapa en klass som heter **Pet** med attributen; namn (string), art (string) och energi (int).

Skriv en konstruktor som tar namn och art, och sätter energin till 50.
Lägg till två metoder:

- Eat(int amount) som ökar husdjurets energi
- Play(int time) som minskar husdjurets energi

Gör följande i "Program.cs":

1. Skapa ett Husdjur‑objekt.
1. Låt djuret leka och äta några gånger.
Skriv ut energin efter varje steg.

<details>
<summary>Lösningsförslag Övning 3</summary>

```csharp title="Klassen Pet"
class Pet
{
    private string _name;
    private string _species;
    private int _energy;

    public Pet(string name, string species)
    {
        this._name = name;
        this._species = species;
        this._energy = 50;
    }

    public string GetName()
    {
        return this._name;
    }

    public int GetEnergy()
    {
        return this._energy;
    }

    public void Eat(int amount)
    {
        this._energy += amount;
    }

    public void Play(int time)
    {
        this._energy -= time;

        if (this._energy < 0)
        {
            this._energy = 0;
        }
    }
}

```

Vi har följande kod i huvudprogrammet.

```csharp title="Huvudprogrammet, kod i Program.cs"
// Skapa ett Husdjur‑objekt
Pet p = new Pet("Milo", "Cat");

// Lek en stund (10)
p.Play(10);
Console.WriteLine("Energy: " + p.GetEnergy());

// Fyll på med energi (20)
p.Eat(20);
Console.WriteLine("Energy: " + p.GetEnergy());

// Lek en lång stund (100)
p.Play(100);
Console.WriteLine("Energy: " + p.GetEnergy()); // Energin har tagit slut
```

</details>

## Övning 5 - En klass Teacher

Vi har en klass som heter **Teacher** som ser ut så här:

```csharp title="Klassen Teacher"
class Teacher
{
    private string name;

    public Teacher(string name)
    {
        name = name;
    }

    public string GetName()
    {
        return name;
    }
}
```

Vi har följande kod i huvudprogrammet.

```csharp title="Huvudprogrammet, kod i Program.cs"
Teacher teacher = new Teacher("Anna");
Console.WriteLine($"Name: {p.GetName()}");
```

**Frågor att besvara:**

1. Vad skrivs ut?


<details>
<summary>Svar Övning 5</summary>

1. Svarade du "Name: Anna"? Men tyvärr är det fel. Det som skrivs ut är "Name: " och så inget namn. Med denna konstruktor så får du varningen "Assignment made to the same variable; did you mean something else?". Genom att uppdatera konstruktor till:
```csharp title="Uppdatera konstruktorn med this"
class Teacher
{
    private string name;

    public Teacher(string name)
    {
        this.name = name;
    }

    public string GetName()
    {
        return this.name;
    }
}
```
Nu så skrivs "Name: Anna" ut. Men koden följer inte namnkonventionen för C#, där privata variabler ska heta `_name` med ett understreck i början av namnet. Då blir det tydligare skillnad på `_name` och `name`. Det är bra att alltid skriva `this` framför attribut och metoder som tillhör objektet.

Skriv alltid `this` vid användning objektets attribut för att visa att vi arbetar med objektets data och undviker vanliga fel. Det brukar leda till en bättre och snabbare förståelse av objektmodellen. I slutet av kursen (kmom01/10 projektet) och i produktion (arbetslivet) så kan ni som vill hoppa över `this`.


</details>
